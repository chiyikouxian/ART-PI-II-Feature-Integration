# 简介
生成GB2312、GBK与Unicode之间的编码对照表，方便单片机上用查表的方式实现字符编码的转换

# 基本使用方法
* 将`str_code_cvt.h`和`str_code_cvt.h`，以及另外4个c文件字符查找表加入单片机的工程中
* 修改`str_code_cvt.h`文件中的配置，选择需要转换的字符编码
* 参考`main.c`的使用方式转换字符编码

# 进阶用法
如果现有的4个字符查找表不满足你的需求，可以自行修改`character_code_generator.py`生成你需要的字符表
* 安装python3
* 修改并运行这个脚本，当前目录下会成4个c文件，分别对应GB2312与Unicode，GBK与Unicode之间的转换表

# 说明
* 生成的C文件默认为utf-8编码，Keil打开文件默认是GBK编码，如需转码就随便找个文本编辑器打开文件，然后另存为选择gbk编码
* 对于懒人们，这里提供已经生成好的4个查找表
* 资源特别小的单片机用GB2312与Unicode的查找表就足够了，GB2312足以覆盖日常生活中99%的汉字
* 资源多一些的用GBK与Unicode的查找表
* 资源更多的就去用libiconv，别在这儿凑热闹（狗头.jpg）
